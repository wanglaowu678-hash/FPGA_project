# report/ — 设计报告与协作记录

本目录用于存放设计文档。当前已包含：

| 文件 | 说明 |
|---|---|
| `schematic.pdf` | 系统设计框图 |

## 建议补充

按竞赛要求，本目录可继续补充：

- `design-report.md` / `.pdf`：设计报告（系统方案、模块划分、时序与资源、测试结果）；
- `ai-collaboration-log.md`：大模型协作记录（提示词、采纳/否决的修改、验证结论）；
- `timing-report.txt`：综合与实现的关键时序路径摘要；
- `resource-utilization.md`：LUT/FF/BRAM/DSP 利用率。

> 报告中出现的图片、表格等资源建议放在 `report/assets/`，文件名同样保持小写下划线风格。
