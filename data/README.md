# data/ — 测试数据与参考结果

本项目的输入为 **OV7725 实时摄像头画面**，不依赖离线数据集，因此仓库中不包含测试图片或视频。

## 参考结果

上板后可预期：

| 现象 | 说明 |
|---|---|
| VGA 画面实时显示 | 摄像头原始画面 + 二值分割 + 质心标注 |
| 三路阈值可独立采样 | 按 BTNL/BTNC/BTNR 分别锁定一种目标颜色 |
| UART 输出 | 38400 8N1，SW2 选择坐标或角度 |
| 数码管/LED | BCD 数值与状态指示 |

如需把测试素材纳入仓库，建议在 `data/` 下按 `images/`、`videos/`、`expected/` 组织，并在 README 中注明采集条件（光照、距离、目标颜色）。
